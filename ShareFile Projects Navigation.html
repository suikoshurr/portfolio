MODULE 01 / CONTEXT — "PROJECTS" IN SHAREFILE

A Project is a time-boxed container for a full client engagement, and everything it produces lives in a tab — requests, documents, signatures, files, billing, custom tables. Two personas live here: Owners, who shape the structure, and Team members, who navigate it all day. By the time I took this on as acting lead, tabs were the container's spine — and its weakest joint. Steady user feedback about wrangling so many tabs finally pushed this long-standing debt to the top.

MODULE 02 / THE TAB STRIP AS IT SHIPPED
FIG. 02-A · THE OLD TAB STRIP IN MOTION — IDENTICAL, UNORDERED, OVERFLOWINGPRE-UPLIFT UI · RECORDING

Watch the recording and the debt announces itself. Every tab is a bare text label — a request list looks exactly like a billing table. Order is fixed at creation, so the tab a team uses daily can sit eleventh. Anything past the viewport simply vanishes: no scrollbar, no indicator, no count. And the actions that manage all of this — add, edit, create template — hide inside a "More" menu on the toolbar, nowhere near the tabs they act on.

No identity — 13 tabs, one typeface, zero icons
No order — tabs frozen in creation sequence
No horizon — overflowed tabs disappear silently
No verbs — add / edit / template buried in "More"

Twenty-five people, one complaint.

MODULE 03 / EXPLORING THE PROBLEM SPACE

We ran 25 moderated studies with SMB users — the owners and relationship managers who live inside projects. Sessions were built around real navigation tasks: find a tab, add a table, tell two tabs apart. The same frustrations surfaced in different accents.

"When I have too many tabs, it becomes overwhelming — they all look the same, and I can't figure out which one does what. Adding new tables is even harder since the 'add' option is buried."

"As my tabs increase, I lose visibility and control. The 'add' option is hard to find, and I wish templates would indicate whether they support integrations or not."

Three tracks of trouble.

MODULE 04 / TOP IDENTIFIED PROBLEMS
TRACK 01
Tab management

Tabs are identical text labels frozen in creation order. There's no way to reorder, no iconography, no grouping — a strip of thirteen tabs reads as one grey blur.

TRACK 02
Unclear interactions

Add, edit and create-template live in a toolbar "More" menu — far from the tabs they act on. Import from other tools exists, but nobody can find it. Blank states offer no path.

TRACK 03
Access & visibility

When tabs overflow the viewport they vanish — no indicator, no count, no dropdown. The add action scrolls away with them. Owners literally lose parts of their own project.

The fix — click it in.

MODULE 06 / THE ADD, TEMPLATE & IMPORT FLOWS

Exposing the add button was the easy half — you just clicked it in step 5 of the prototype above. The harder half was making what's behind it worth exposing: three full flows, each designed against a specific research finding.

FIG. 06-A · ZOOM — EVERYTHING BEHIND THE PLUS2× DETAIL

Before this work, "import" technically existed — buried so deep that in 25 studies not one participant found it unprompted. The new add menu makes the whole creation surface legible in a single click: start blank, start from a template, or pull data straight in from a CSV or a connected app. The two paths users never found are now the two the menu leans on hardest.

F-01 · BLANK TAB
Start from zero, guided

A blank tab opens into a named, typed setup — table view first — instead of the unlabelled void users used to abandon.

F-02 · TEMPLATES
Templates that disclose

A sortable template gallery where every card states what it does — and whether it supports integrations. Rose Mary's ask, verbatim, shipped.

F-03 · IMPORT
Import, finally findable

CSV upload and app connections — Podio, QuickBooks, Salesforce — promoted from a buried menu to a first-class path with its own guided connection flow.

Proven before shipped.

MODULE 07 / VALIDATION

We took the redesigned system back to the same population that surfaced the problems — 13 moderated sessions against the three tracks, run through a clickable prototype, with a tasks-and-insights board tracing every stumble to a specific control. The riskiest bet, the import flow, was tested against QuickBooks, Salesforce and Podio connections, because integration drop-off was the number we most needed to move.
