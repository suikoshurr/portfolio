01

Two identity levels

The system runs on exactly two skins. One accent colour per level — never both in the same page. This is what separates a case file from the pages that frame it.

LEVEL 1
Control Tower
SIGNAL GREEN
Landing, hub & connective pages. Cool paper #f4f6f7, ink blocks, green reserved for live/available/OK signals and the Lab CTA. Boot sequence on load.
LEVEL 2
Case File
DOSSIER GOLD
Individual case studies. Warm cream #faf6ec with dot-grid hero, gold accents, warm hairlines, and the dossier meta bar. Ink blocks still punctuate for rhythm.
